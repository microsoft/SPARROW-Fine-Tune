    Crops for the classifier

      Choose what happens to these images before the snapshot. Boxes you already drew or reviewed are kept; only the images listed here are touched.

      DINO feature preparation

      Creating a snapshot prepares the features needed for DINO training. Only crops without valid cached features need extraction.

      A first model starts from weights pretrained on ImageNet, a large general photo collection. A finished model chosen below sets its own architecture.

      Base model (starting weights)

      Start from a model trained here, using the snapshot chosen above. The finished model is never changed; training makes a new version that records which model it started from.

      Training settings (optional)

      The defaults suit most datasets. Change them only if a first model is not good enough.

      More passes can learn more but take longer.

      Saves time; the best model so far is kept.

      These photos are not trained on; they measure how well the model works. Photos from the same camera or sequence stay together.

      Helps the model cope with new cameras and lighting. Turn off only if orientation or colour tells the classes apart.

      Cautious can help when training results jump around; Fast can help when the model learns too slowly. Standard suits most datasets.

      Photos are resized to this size for training. 1280 finds small or distant animals better but uses about 4 times the GPU memory and time. It follows the starting weights; change it if needed.

      Batch size (images per training step)

      Default 16. Automatic falls back to a small batch on a CPU.

      Predictions less confident than the threshold are labelled "unknown". A lower target labels fewer images "unknown" but makes more mistakes. With few images per class, try 90% or 85%.

      After training, the stock model is scored on the same held-back photos. If it does better, the model page says so and activating the new model asks you to confirm.

      Later corrections create a new snapshot; existing ones never change.
